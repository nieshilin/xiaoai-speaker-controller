# 小爱音箱控制台（Electron + JavaScript）

Windows 桌面端的小爱音箱遥控器。走小米 **MiNA 云端通道**下发播放指令，音箱不需要开端口、不需要 token；音乐来源支持**网易云 / QQ 音乐在线搜索**和**本地文件局域网推流**。

## 功能

- **扫码登录小米账号**：手机米家 App 扫码确认即可，不输密码；登录态保存在本机，之后启动自动续期
- **在线音乐（双音源）**：网易云音乐 / QQ 音乐切换搜索，点歌曲直接让音箱播放
- **音源本地代理**：在线歌曲不直接把平台 CDN 直链交给音箱，而是先经内置媒体服务（`/proxy/<音源>/<歌曲 id>`）中转，由电脑带正确 UA/Referer 取流，规避音箱端拉不到 CDN、vkey 过期、跨域 UA 拦截等问题
- **音乐账号登录**：点「登录账号」会弹出内嵌登录窗口（网易云 / QQ 音乐各一个），在网页里扫码或账密登录后自动提取 Cookie 保存到本机；也可以手动粘贴 Cookie
- **本地音乐**：内置 HTTP 媒体服务（带 Range 支持），把本地 mp3/flac/wav/m4a 等推流给音箱，支持上一首/下一首
- **基础控制**：播放 / 暂停 / 停止 / 状态查询 / 音量
- **语音播报**：输入文字让音箱用 TTS 念出来
- **关于应用 / 版本更新**：右上角版本号或底部「关于应用」打开关于面板，展示运行时版本并检查 GitHub Release 的新版本，发现新版会亮红点提示，可直接下载安装包
- **型号自适应**：L05B/L05C/LX04/LX05 等型号自动改用 `player_play_music` 下发，其余走 `player_play_url`

## 使用

```powershell
npm start        # 启动
npm run check    # 离线自检
npm run e2e      # 端到端 UI 测试（模拟小米云端）
npm run dist     # 打包 Windows 安装包（输出 release/）
```

1. 首次使用点「扫码登录」，用米家 App 扫码并确认
2. 下拉框选择音箱，状态灯变绿
3. 「在线音乐」里搜索歌曲，点「播放」即从音箱出声
4. 播放本地文件时，音箱通过 `http://<电脑IP>:8931` 拉流；首次失败请在 Windows 防火墙放行本程序的「专用网络」

## 会员歌曲

未登录时，版权 / VIP 歌曲可能取不到音源：

1. **推荐**：点「登录账号」→ 在弹出的内嵌窗口里登录（网易云用手机/扫码，QQ 音乐用 QQ 扫码），成功后自动保存，Cookie 只存本机
2. 或者点「粘贴 Cookie」手动保存：网易云需要含 `MUSIC_U`，QQ 音乐需要含 `uin` 和 `qm_keyst`（在 y.qq.com 登录后从浏览器开发者工具复制）
3. QQ 音乐的会员歌曲还需要账号本身有会员，否则会提示「需要 QQ 音乐会员」

免费曲目不登录也能播放（QQ 音乐匿名限 128k，登录后按账号权益取更高音质）。

## 结构

```
main.js            Electron 主进程：窗口、IPC、媒体服务、账号与音源编排
preload.js         contextBridge 桥接
src/mina.js        小米账号登录（扫码 + passToken 续期）与 MiNA ubus 指令
src/music.js       网易云 / QQ 音乐：搜索、取播放地址、歌词、登录态判定
src/mediaServer.js 本地文件 HTTP 推流（Range 206）
src/store.js       本机配置读写
renderer/          界面
scripts/           自检、端到端测试、模拟小米云端
```

## 排错

- **播放地址无效 / 歌曲放不出来**：多为版权或会员限制，登录对应平台账号后重试；试听片段会在提示里注明
- **QQ 音乐登录后仍提示需要会员**：该曲目需要 QQ 音乐会员权益，与登录状态无关
- **音箱离线 / 拒绝指令**：确认音箱在线，且登录的小米账号就是绑定音箱的账号
- **本地文件不响**：检查防火墙入站；日志里能看到音箱是否来拉流
- **登录态失效**：重新扫码即可（小米的 passToken 长期有效，一般很少遇到）
- **换取 serviceToken 失败（401）**：小米返回的 `nonce` 是 19 位大整数，`JSON.parse` 会丢精度导致签名错误；`src/mina.js` 已做保精度处理并在自检里加了回归用例，改动时不要去掉
